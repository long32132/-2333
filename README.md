# 大话骰子（玩家 vs 电脑）

一个带界面的 1v1 大话骰子网页小游戏，支持现场叫骰氛围和输家喝酒动作演出。

## 玩法规则

- 玩家与电脑 1 对 1。
- 双方每局各 5 个骰子，点数可见。
- 轮流叫骰，格式为“数量 + 点数”。
- 叫骰必须严格变大：先比数量，数量相同比点数。
- 在自己回合可选择“开盅”。
- 在自己回合也可选择“劈”。
- **1 为万能**：结算任意点数时，`1` 都计入该点数数量。
- 开盅：直接判定，输家喝 1 杯。
- 劈（2杯链路）：
  - 被劈方不接受：视为认输，喝 1 杯。
  - 被劈方接受：开盅判定，输家喝 2 杯。
  - 被劈方可反劈：升级到 4 杯链路。
- 反劈（4杯链路，封顶）：
  - 被反劈方不接受：视为认输，喝 2 杯。
  - 被反劈方接受：开盅判定，输家喝 4 杯。
  - 被反劈方不能再反劈。
- 玩家累计喝到 20 杯判定“喝醉”，播放 5 秒醉酒动画并显示文明调侃文案。

## 运行方式

直接双击 `index.html` 即可打开。

或在项目目录启动静态服务：

```bash
python -m http.server 8000
```

然后访问：`http://localhost:8000`
